# PharmaManager Frontend

React.js frontend for PharmaManager.

## Stack

* React.js
* Vite
* JavaScript
* Axios
* TailwindCSS
* React Router DOM
* React Hot Toast

---

# Frontend Structure

```bash
src/
│
├── api/
├── components/
├── hooks/
├── layouts/
├── pages/
├── routes/
└── utils/
```

---

# Features

* Authentication pages
* Dashboard
* Medication management
* Sales management
* Protected routes
* Responsive UI
* Loading states
* Toast notifications
* Error handling

---

# Installation

## Install dependencies

```bash
npm install
```

---

## Configure environment variables

Create `.env` file:

```env
VITE_API_BASE_URL=http://localhost:8000/api
```

---

## Start development server

```bash
npm run dev
```

Frontend available at:

```txt
http://localhost:5173
```

---

# Docker

From project root:

```bash
docker compose up --build
```
